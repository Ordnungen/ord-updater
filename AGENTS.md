# AGENTS.md — ord-updater

Локальная памятка по этому плагину. Общие правила — в корневом [`../AGENTS.md`](../AGENTS.md) и `../docs/`:
при конфликте приоритет у корневых документов. Идея и почерк продукта — `../docs/IDENTITY.md`,
план приведения к стандарту — `../docs/PLAN.md`, долги — `../docs/PLUGINS.md` §1.

## Состояние

`1.0.4`, опубликован в каталоге сообщества. Написан до стандарта: один файл `src/main.ts`, проверок не было.
Заход 20 приводит его к общему виду — порядок работ в `../docs/PLAN.md`.

Что этот плагин делает: пишет в заметки свойства (`date`, `update`, `tags`, `links`), создаёт и обновляет
индексные заметки папок (`<Имя папки>.md`) и переименовывает файлы и папки с пробелами. Он **меняет заметки
пользователя**, поэтому любая правка логики свойств или переименований — только с проверкой и только через
API, который сохраняет данные.

## Что важно знать при правках

- **Свойства** — только `FileManager.processFrontMatter`. Ручной разбор YAML запрещён (`../docs/STANDARD.md`):
  он теряет вложенные объекты, блочные значения и типы. Запись содержимого — `Vault.process`.
- **Переименование** — только `FileManager.renameFile`: `Vault.rename` не обновляет ссылки в других заметках.
- **Пути** — `normalizePath`; не склеивать `'/'` вручную (`${parent?.path || ''}/${name}` даёт `//name` в корне).
- **Удаление** — `FileManager.trashFile` и только того, что создал плагин: признак индексной заметки — тег
  `index`, который плагин сам поддерживает.
- **Имена в правилах недопустимы**: `src`, `dist`, `build`, `node_modules`, `README.md` — это настройки с
  разумными значениями по умолчанию, а не константы в коде.
- **Строки** — через `t()`; `isRu() ? '…' : '…'` в коде не бывает. Язык — `getLanguage()` с запасным
  `navigator.language` (плагин поддерживает Obsidian с 1.7.2, где `getLanguage()` ещё нет).
- **Язык кода** — английский: идентификаторы, комментарии, коммиты, README. Русский — только в заметках
  хранилища и в `tools/` (проверки печатают отчёт по-русски).
- **`main.js` в репозитории** — осознанное решение (`../docs/STANDARD.md` §1): пересобирать вместе с `src/`.
- Не трогать настоящие заметки при проверках: каталоги кейсов работают на заглушке, отчёт по хранилищу —
  только чтение.

## Проверка перед «готово»

```powershell
npm run check    # typecheck + lint
npm run cases    # каталог кейсов на заглушке Obsidian
npm run analyze -- "C:\Users\Ordnung\Documents\OBSIDIAN\Veritas"   # отчёт по хранилищу, без записи
npm run build    # main.js должен быть пересобран
```

Плюс то, что машина не проверит: светлая и тёмная темы, мобильная эмуляция, всплывающее окно, переименование
папки с пробелами в отдельном dev-хранилище. Поведение самого плагина проверяется в dev-хранилище, а не в
основном: основное — это рабочие заметки автора.
